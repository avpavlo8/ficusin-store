# Проверка записи через GitHub MCP

Временный файл. Создан для проверки того, что коннектор получил
installation-токен и может писать в репозиторий.

До установки app `Claude Github MCP Connector` любая запись падала с
`403 Resource not accessible by integration`.

Этот файл можно удалить вместе с веткой `mcp-write-access-test`.
