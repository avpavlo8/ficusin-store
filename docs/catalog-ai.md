# AI-подготовка товарной карточки

AI работает только в админке и никогда не публикует результат самостоятельно. Перед генерацией импортированные размеры объединяются в одну PRODUCT-карточку с несколькими SKU.

Кнопка «Подготовить с AI» отправляет исходное название, код СБИС и разрешённую категорийную схему на backend. Backend использует Responses API, web search и JSON Schema. В ответе показываются текст, FAQ, характеристики, предупреждения, источники и промпт обложки. Менеджер принимает или отклоняет предложение; сохранение остаётся обычным явным действием формы.

Обложка генерируется отдельной кнопкой после проверки сорта. Image API возвращает WebP, backend кладёт его в своё S3 и назначает главным медиа PRODUCT. Реальные фотографии конкретных SKU остаются в галерее вариантов.

Секреты хранятся только в окружении: `OPENAI_API_KEY`. Пустой ключ отключает AI с HTTP 503, не влияя на каталог, импорт или редактирование вручную. Модель текста задаётся `OPENAI_TEXT_MODEL`.

Ограничения: AI может ошибаться в сорте и ботанических свойствах. Источники необходимо открыть перед публикацией; токсичность, условия ухода и точные характеристики нельзя принимать только по уверенной формулировке модели.
