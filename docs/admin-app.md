# Приложение сотрудников

Панель `https://ficusin.ru/admin` устанавливается отдельно от магазина как
«Фикусин — управление». Собственные manifest ID `/admin`, название, иконки,
стартовый адрес и ярлыки заказов, закупок и каталога описаны в
`public/admin.webmanifest`. Магазин сохраняет свой manifest и идентификатор.

Сервер подставляет метаданные приложения в исходный HTML `/admin` и его
вложенных адресов, а также входа с `returnTo=/admin…`: Safari получает нужные
название и apple-touch-icon ещё до выполнения JavaScript. Клиент повторяет
это для локального Vite preview. При ответе API 401 вход возвращает в выбранный
раздел. При открытии страницы с уже недействительной сессией существующая
серверная проверка возвращает после входа на `/admin`. Доступ к API по-прежнему
проверяет сервер по ролям сотрудников.

Установка выполняется через меню браузера: на iPhone — Safari → «Поделиться»
→ «На экран Домой», в Chrome/Edge — пункт установки приложения. Прежняя кнопка
«Приложение» и компонент `AdminAppInstall` удалены. Клиент подавляет автоматическое
предложение установки в админке, сохраняя manifest и возможность ручной установки.
В установленном режиме `/admin` открывает заказы, явно выбранный раздел сохраняется.
Логотип магазина ведёт на `/`, логотип управления — на `/admin`.

Обе установки используют существующие backend, сессию и `/sw.js`. Новый worker
не создаётся: это сохраняет действующие push-подписки. API и персональные данные
не кэшируются. Офлайн-редактирование заказов не поддерживается. Переход в магазин
или на вход выходит за scope `/admin`; браузер может показать адресную строку.

SVG иконки создан из существующего векторного знака `public/favicon.svg`:
зелёный фон рабочего пространства и знак списка задач отличают управление от
магазина. PNG 180/192/512 и maskable экспортированы из SVG.
