# Базовый стиль публичного сайта

Зафиксированный визуальный baseline восстановлен 30 августа 2026 года из
состояния `a36e5e0`, предшествовавшего серии перехода на универсальную
дизайн-систему.

## Что считается базовым

- тёплый бумажно-бежевый фон;
- глубокий зелёный текст и навигация;
- терракотово-оранжевые основные кнопки;
- крупный ботанический hero и интерьерные подборки;
- прежняя композиция PDP, корзины и пошагового checkout;
- единые шапка и подвал на публичных страницах;
- мобильная версия является адаптацией этого же стиля, а не отдельной темой.

Референсное состояние относится только к внешнему виду. Серверная корзина,
остатки, варианты SKU, фильтры, оформление заказа, платежи, доставка и
интеграции продолжают использовать актуальную бизнес-логику.

## Правило изменений

Изменение публичного дизайна не должно одновременно заменять бизнес-логику.
Новая разметка обязана сохранять текущие API-контракты, доступность и
регрессии Playwright. Крупный визуальный редизайн выполняется в отдельной
ветке и вливается только после визуального утверждения.

## Обязательные проверки

- `frontend`: lint, проверка мёртвого CSS и production build;
- `layout`: Chromium desktop, iPhone/WebKit и Android/Chromium;
- PDP: товар с фотографиями, товар без фотографии, варианты, остаток,
  предзаказ, вкладки, отзывы и рекомендации;
- каталог: категории, подборки, поиск, режимы фильтров и мобильный overflow;
- корзина/checkout: серверное состояние, лимит по остатку, валидация полей,
  доставка, оплата и успешный заказ.

При падении `layout` workflow всегда сохраняет `playwright-report` и
`test-results`, включая screenshot, trace и сведения об ошибке.
