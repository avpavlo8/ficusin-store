# Дизайн-система публичного frontend

## Структура CSS

- `tokens.css` — семантические токены и временные aliases для legacy-кода.
- `base.css` — reset, глобальная типографика, доступность и старые немигрированные layout-правила.
- `components.css` — единственный источник общих кнопок, полей, карточек, контейнеров и badges.
- `header.css` — единственный источник публичной шапки, меню и плашки разработки.
- `shell.css` — поиск, мобильная нижняя навигация и каркас публичных страниц.
- `storefront.css`, `product.css`, `checkout.css`, `account.css`, `footer.css` — стили разделов.
- `admin*.css`, `pdp-admin.css` — только административный интерфейс.

Импорты идут от общих правил к разделам. Новый компонент нельзя исправлять правилом в конце каскада: общий стиль меняется в `components.css`, раскладка раздела — в его файле.

## Обязательные токены

Цвета: `--color-text`, `--color-text-muted`, `--color-primary`, `--color-primary-hover`, `--color-accent`, `--color-background`, `--color-surface`, `--color-border`, `--color-success`, `--color-warning`, `--color-error`, `--color-focus`.

Размеры: `--space-1`…`--space-8`, `--radius-sm`…`--radius-pill`, `--shadow-sm`…`--shadow-lg`, `--container-content`, `--container-wide`, `--container-gutter`, `--control-sm`…`--control-lg`, `--font-size-xs`…`--font-size-2xl`, `--z-*`, `--header-h`, `--development-notice-h`.

Контрольные ширины: 360, 390, 768, 1024, 1440 и 1920 px. CSS custom properties `--breakpoint-*` документируют общие значения, но в `@media` используются числовые значения, поскольку custom properties там не поддерживаются.

## Правила

- Обычный текст — не меньше 14 px. `--font-size-xs` разрешён только для служебных подписей с `--color-text-muted` или более контрастным цветом.
- Все интерактивные элементы используют общий `:focus-visible`; не удалять outline локально.
- Анимации обязаны корректно отключаться через `prefers-reduced-motion`.
- Интерфейсные иконки — SVG с `stroke-width: 1.75`, round caps/joins. Unicode-глифы не использовать.
- Публичные компоненты не размещать в `admin*.css`.

## Выполненная миграция

Из `storefront.css`, `product.css` и `checkout.css` удалены локальные реализации шапки, её действий, поиска и dropdown-меню. Из `account.css` перенесён avatar badge, из `admin.css` — случайно попавшие туда стили мобильного публичного меню. Удалено общее правило подчёркивания всех `.desktop-nav a`, которое перечёркивало ссылки dropdown.

На токены и общие primitives переведены шапка, dropdown/menu, поиск, публичная плашка, общие кнопки и поля. Главная, PDP, корзина/checkout, account, legal pages и footer пока сохраняют собственные legacy-layout и локальные палитры; их нужно мигрировать по разделам без изменения бизнес-логики.

## Инвентаризация

`npm run lint:css` проверяет классы CSS против TSX и допускает только явно перечисленные динамические классы. На момент создания системы подтверждены 552 используемых класса, поэтому остальные правила не удалялись без отдельного подтверждения. Исторические точки адаптивности остаются в legacy-файлах (560, 760/768, 800/850/900, 1020/1024, 1100/1200, 1450 px); новые общие компоненты используют 480, 768, 1024 и 1440 px и проверяются также на 360, 390 и 1920 px.
