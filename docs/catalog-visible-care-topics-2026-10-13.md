# Темы ухода на карточке: проверка заглушек

Снимок 294 опубликованных карточек 13 октября показал: паспортный свет и полив заполнены у 292, влажность у 58, температура у 57, грунт у 58, пересадка у 59, подкормка у 57, рост у 55. Витрина при этом показывала все восемь вкладок с текстом «Информация для этого растения готовится». Пустые вкладки скрыты; видны только рекомендации, действительно записанные в паспорт. Вкладка вопросов показывается только при наличии вопроса и ответа. Это убирает обещание готового контента из интерфейса, не подставляя универсальные советы за персональные.

После уточнения владельца карточка #858 — композиция из метасеквойи, #863 — гиппеаструм, продававшийся под названием «амариллис». Для этих двух карточек отдельно подготовлены название, длинное и краткое описания, уход и восемь тем паспорта с точной защитой старых значений. Источники: [RHS о метасеквойе](https://www.rhs.org.uk/plants/533436/metasequoia-glyptostroboides-bonsai/details), [RHS об уличном бонсай](https://www.rhs.org.uk/plants/types/trees/bonsai), [RHS о гиппеаструме](https://www.rhs.org.uk/plants/hippeastrum/growing-guide).

Следующий этап — персонально дополнить пустые темы для остальных растений. Одна только правка отображения их не заполняет. Необходимы источники по каждому виду и проверка уже существующих карточек, особенно старых шаблонных описаний из СБИС.

## Проверенное заполнение тем

По уточнению владельца подготовлен отдельный пакет для 153 точно сопоставленных опубликованных карточек. Он добавляет 861 рекомендацию по влажности, температуре, грунту, пересадке, подкормке и, где позволяет источник, темпу роста. Тексты и ссылки на ботанические руководства находятся в `reviewed-plant-passports-2026-10-13.json` и `plant-passport-sources-2026-10-13.md`. Миграция `20261013_d_reviewed_plant_passports.sql` заполняет только пустые ключи при точном совпадении кода и текущего названия карточки; существующие правки сохраняются.

После этого пакета по снимку живых данных до выкладки ожидаются 81 пустая тема пересадки и 141 пустая тема роста. Это ещё не завершение ухода по всем растениям. Остаток включает разные виды бонсай, смешанные композиции и товары с недостаточной идентификацией. Их следует прорабатывать отдельно, а не переносить готовую рекомендацию от другого растения.

## Следующий проверенный пакет

После успешной выкладки первых 153 карточек живой API подтвердил все добавленные темы без пропусков. Следующий пакет добавляет 311 текстов для ещё 57 карточек. В нём, в частности, различаются зимовка разных бонсай, уход за хищными растениями и воздушными тилландсиями. По свежей выгрузке после первого пакета ожидается, что после второго пустая тема пересадки останется у 27 карточек, а тема роста — у 93; точные числа следует подтвердить после выкладки. Для спорных видов и составных товаров не подставляем уход от похожего растения.

При проверке второй партии выявлено и исправлено противоречие в длинном описании #64: прежний текст называл листопадную лжелиственницу вечнозелёным комнатным растением. Правка выполняется только при совпадении старого текста и идентичности карточки; источники приведены в миграции `20261013_f_fix_pseudolarix_description.sql`.
