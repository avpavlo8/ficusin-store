# Инструкции сотрудников

Раздел `/admin?section=instructions` доступен всем вошедшим сотрудникам панели,
включая менеджера без права менять интеграции. Используется общий workspace.
Чтение инструкций не запускает операций с заказами, товарами или внешними площадками.
Кнопка «?» в первом шаге инструкции СДЭК запрашивает данные для входа с сервера.
Запрос доступен сотрудникам с `dashboard.read`, ответ не кешируется. Логин и пароль
задаются на сервере через `CDEK_OFFICE_LOGIN` и `CDEK_OFFICE_PASSWORD`
отдельно от ключей API доставки. В локальном предпросмотре только демоданные.

В каталоге опубликованы две инструкции. В разделе СДЭК доступно создание заказа,
в «Общих инструкциях» — раскрой пенопласта для коробок. На главной показаны
девять кнопок с логотипами: Saby, Wildberries, Ozon, СДЕК, Сайт, Flowwow, Avito,
5Post и Касса. У разделов без инструкций показано состояние «Инструкции готовятся».
Общий блок виден на главной каталога.

В памятке по пенопласту `boxLayouts` задаёт 12 размеров коробок. Каждый пункт
открывает соответствующую карту раскроя для листа 100 × 60 см толщиной 3 см.
Карты хранятся как PNG в `public/assets/instructions/v1/general-cut-foam/`.
Открытую карту можно увеличить, скачать или распечатать.

Поиск работает по всем разделам, даже если открыт конкретный сервис.
Совпадения в заголовках и кратких описаниях стоят выше упоминаний в тексте шагов.
Результаты имеют мягкий цвет и текстовую подпись сервиса: Wildberries —
светло-фиолетовый, Ozon — светло-синий, СДЕК — светло-зелёный. Другие разделы
также имеют свои спокойные оттенки; цвет не заменяет название.
Логотипы поставляются локально; адреса источников сохранены в
`public/assets/instructions/logos/sources.json`.

Поиск учитывает названия, шаги и русские варианты названий
сервисов («вб», «озон», «флаувау», «сдек»). Фильтр, запрос и выбранная инструкция
сохраняются в URL (`service`, `q`, `guide`); работают перезагрузка и история браузера.
Из открытой инструкции можно перейти к списку её сервиса или на главную
страницу каталога инструкций.
На телефоне раздел находится в меню «Ещё».

Шаги читаются как текст в HTML. Изображение можно увеличить, скачать или
распечатать вместе с инструкцией. Печать ожидает декодирования всех картинок
выбранной инструкции. При ошибке картинку можно загрузить снова.
Инструкция по созданию заказа СДЭК идёт в один столбик и начинается с
текстового шага со ссылкой на личный кабинет.

## Содержание и границы достоверности

Снимки создания заказа СДЭК от 23 ноября 2026
показывают путь от списка заказов до выбора ПВЗ клиента. Идентификаторы и контактные
данные закрыты в исходных файлах. Поля и кнопки выделены маркером, пояснения
находятся в HTML. Финальное подтверждение заказа пока не описано.
В шаге получателя есть ссылка на CDEK ID и порядок исправления контактов после
получения трек-номера. Шаг оплаты объясняет выбор плательщика за доставку.
В шаге выбора города приведён пример поиска населённого пункта по адресу ПВЗ.
В инструкции по созданию заказа СДЭК блоки «Проверка» убраны.
Перед добавлением новых снимков удаляйте из кадра частные контакты,
реальные заказы и секреты.

## Обновление картинок

Источник текста и аннотаций — `frontend/src/instructions/content.json`.
Очищенные исходные снимки хранятся в `scripts/instruction-screens/`. В сборку
входят размеченные копии из `public/assets/instructions/v1/`.
Для `imageStyle: "outline"` генератор рисует обводку маркером по координатам
`outlines` (x, y, ширина, высота в пикселях) поверх снимка из `screen`.
Текст шага находится над изображением. Поле `imageFile` задаёт имя с версией
для обновления кеша. Поле `example` добавляет второй снимок в тот же шаг.
Для шага со ссылкой без изображения используется `imageStyle: "text"`.

После правки текста или снимков пересоберите картинки:

```sh
cd e2e
npm ci
npx playwright install chromium
cd ..
node scripts/build-instruction-images.mjs
```

Генератор добавляет разметку на локальные снимки и сохраняет PNG
в `public/assets/instructions/v1/`. PNG и manifest
коммитятся вместе с изменённым JSON. Неиспользуемые изображения старых шагов
нужно удалить при изменении состава инструкций. При смене общего формата
выпустите новую версию каталога и измените путь в `AdminInstructions`.
Эти ассеты публичные и могут кэшироваться как статические файлы; в них должны
оставаться только безопасные учебные данные.

Проверка `admin-instructions.spec.ts` проходит обе инструкции, их PNG,
пустые разделы, глобальный поиск, историю, раскрытие и скачивание карт,
увеличение, повтор загрузки, печать, доступность и ширину мобильной страницы.
Проверки выполняются на собранном frontend с изолированным API.
