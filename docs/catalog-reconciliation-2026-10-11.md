## Следующее безопасное действие

### Правила каналов, выпущенные 11 октября

Миграция `20261011_catalog_channel_scope.sql` перенесла все 324 кода выгрузки в правило SKU на сайте: 59 — `site_only` (сайт, офлайн, Авито), 265 — `marketplaces` (также WB и Ozon). Это подтверждено 11.10 в production по всем 728 активным SKU: 59 `site_only`, 265 `marketplaces`, 404 `unknown`. Правило редактируется владельцем во вкладках связей WB/Ozon. Фильтр «Нужна связь» считает только разрешённые SKU; отдельные фильтры показывают лишние связи и неопределённые правила. Изменение правила не создаёт и не архивирует объявление. Для `site_only` ручное изменение цены сайта больше не готовит предложения цены WB/Ozon. Выпущено в PR #475, smoke `38153408081` прошёл, 15 браузерных проверок. Следующий пакет добавляет такую же проверку закупочных цен перед отправкой на площадки.

Фактические расхождения после выпуска: WB — 16 карточек с хотя бы одним размером без связи, Ozon — 18; лишних связей среди `site_only` не осталось. Подробный список: `docs/catalog-marketplace-gaps-2026-10-11.md`. Число карточек меньше числа SKU, потому что одна карточка может содержать несколько размеров.

1. Для 30 существующих вариантов добавить недостающую X-связь, если она нужна для поиска и сверки. Фикус Одри D22 исправлен.
2. После сопоставления проставить разрешённые каналы отдельно от фактических связей. Связь не должна автоматически публиковать объявление.
3. Для Ozon/WB проверить активность объявлений и вручную сопоставить позиции из разрешённого раздела. Декабрист D9 и Шлюмбергера D18 уже разведены; остальные связи сверять по точному артикулу и размеру, не по одному названию.
4. Владелец поручил распределить растения по названиям. Новые категории и корректировка дерева подготовлены в миграции `20261011_catalog_taxonomy.sql`; опубликованные карточки с уже заданными конкретными категориями она не перезаписывает.
