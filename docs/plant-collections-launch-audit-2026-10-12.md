# Подборки растений перед запуском — 12.10.2026

Источник среза: публичные `GET /api/v1/catalog` и `GET /api/v1/collections` на ficusin.ru. В каталоге 318 опубликованных карточек растений. Девять активных тематических подборок имеют ненулевую выдачу: «Для тёмной комнаты» 17, «Неприхотливые» 116, «Безопасно для питомцев» 22, «Для ванной» 8, «Для офиса» 74, «Вырастает высоким» 6, «Компактные» 3, «Редкий полив» 27, «Для спальни» 64. 141 карточка пока не попадает ни в одну из них.

Подборки вычисляются динамически из атрибутов PIM. Ручные подборки используют отдельную таблицу `collection_products`. Не следует массово вписывать растения в ручные списки или придумывать характеристики по названию: это закрепит неподтверждённые обещания покупателю и перестанет обновляться при исправлении карточки.

## Правила наполнения

- «Безопасно для питомцев» — только когда атрибут `pet_safety=safe` подтверждён по конкретному виду и сорту. Сомнение или отсутствие сведений не равны безопасности.
- «Для тёмной комнаты» — только `light_level=low_light`; в тексте карточки нужно объяснять, что это полутень, а не помещение без дневного света.
- «Неприхотливые» — только подтверждённый `care_level=easy`.
- «Редкий полив» — только подтверждённый `watering=rare`.
- «Для ванной», «Для спальни», «Для офиса» — только явно заполненное `placement` с учётом освещения и влажности конкретного места. Само название вида не даёт такой гарантии.
- «Вырастает высоким» и «Компактные» — только подтверждённый класс высоты. Размер текущего горшка не равен будущей высоте взрослого растения.

Сначала заполняются и проверяются признаки растения в карточках, затем динамические подборки пересчитываются без отдельного импорта. Если у растения нет подходящего подтверждённого признака, оно остаётся в каталоге и своей видовой категории без тематической подборки. Это ожидаемое состояние.

## Обнаруженное расхождение

На момент среза публичный каталог возвращал старые колонки товаров в полях `lightLevel`, `careLevel`, `petSafety` и других, тогда как членство в подборках считалось по PIM. Например, в «Безопасно для питомцев» 22 карточки, а публичный `petSafety=safe` указан только у 17. Исправление в этом блоке выводит в публичных полях сначала значение PIM и использует старую колонку только при отсутствии значения PIM. Правила самих подборок и ручное наполнение не меняются.

Перед выпуском нужно прогнать тест с PostgreSQL (`TEST_DATABASE_URL`) и после выкладки повторить сравнение полей каталога с подборками.

## Проверка пяти карточек из расхождения

Первичный источник для оценки растений — справочник токсичности ASPCA. Он классифицирует [*Aspidistra elatior*, включая пестролистную форму](https://www.aspca.org/pet-care/aspca-poison-control/toxic-and-non-toxic-plants/cast-iron-plant), [рождественский кактус *Schlumbergera bridgesii*](https://www.aspca.org/pet-care/aspca-poison-control/toxic-and-non-toxic-plants/christmas-cactus) и [*Phalaenopsis*](https://www.aspca.org/pet-care/aspca-poison-control/toxic-and-non-toxic-plants/phalaenopsis-orchid) как нетоксичные для кошек и собак. [Clemson Cooperative Extension](https://hgic.clemson.edu/pet-safe-indoor-houseplants-whats-safe-for-cats-and-dogs/) включает в безопасные для питомцев растения как *S. bridgesii*, так и распространённый декабрист *S. truncata*. Поэтому текущий `safe` для карточек #817, #805 и #610 имеет опору в источниках. Это не означает, что поедание любого растения безопасно для желудка: [ASPCA отдельно предупреждает](https://www.aspca.org/pet-care/aspca-poison-control/toxic-and-non-toxic-plants) о возможном расстройстве от растительного материала.

Карточка #829 — **крашеный** фаленопсис. ASPCA оценивает сам род, но не применённый краситель. [USDA APHIS описывает](https://www.aphis.usda.gov/sites/default/files/25-06201p-dea.pdf) окрашивание коммерческих фаленопсисов введением красителя в цветонос; состава красителя в нашей карточке нет. Карточка #543 — бонсай метасеквойя: [ботаническое описание NC State Extension](https://plants.ces.ncsu.edu/plants/metasequoia-glyptostroboides/) подтверждает вид, но не содержит ветеринарного заключения о безопасности для кошек и собак. Для этих двух товаров миграция `20261012_pet_safety_unverified_plants.sql` устанавливает `pet_safety=unknown`; товар остаётся опубликованным, но исключается из «Безопасно для питомцев». Вернуть `safe` можно после проверки состава красителя и отдельного надёжного заключения по виду.
