# Логотип Фикусина

Векторный логотип подготовлен в `/assets/brand/graphite-v1/`. Контуры перенесены из финального векторного комплекта без перерисовки. Текущая подготовленная палитра: тёплый графит `#353630`, слоновая кость `#F9F6EC`.

| Файл | Назначение |
|---|---|
| `wordmark-graphite.svg`, `wordmark-ivory.svg` | Полное название, `viewBox="0 0 1186 370"` |
| `wordmark-graphite.png`, `wordmark-ivory.png` | Прозрачные PNG 1186 × 370, в том числе для писем |
| `mark-graphite.svg`, `mark-ivory.svg` | Отдельная «ф», `viewBox="0 0 400 400"` |
| `avatar-graphite.svg`, `avatar-ivory.svg` | Квадратные аватары с непрозрачным фоном |
| `avatar-graphite.png`, `avatar-ivory.png` | Аватары 512 × 512 |
| `og.png` | Общая карточка ссылки 1200 × 630; карточки товаров сохраняют фотографии товара |

Файлы под `/assets/` кэшируются service worker по принципу cache-first. При следующем изменении содержимого создавайте новую версию каталога, не заменяйте файлы `graphite-v1` на месте.

Корневые favicon, Apple Touch и PWA-файлы сохранены для совместимости со старыми адресами. Активные Apple Touch и PWA-ссылки ведут на `assets/brand/graphite-v1/app-*-v2.png`, а favicon и манифест используют `?v=app-logo-v2`. Тот же знак используется в чатах, подсказке установки и push-уведомлениях. Service worker `v5-app-logo-v2` очищает прежние кэши. Явный `id` манифеста сохраняет прежний адрес установки `/?source=pwa`. HTML-письма используют утверждённый PNG-логотип из той же папки бренда.

`icon-maskable-512.png` имеет непрозрачный фон и уменьшенный знак: весь рисунок помещается в центральный круг радиусом 40% стороны. `push-badge.png` — белый знак 96 × 96 на прозрачном фоне, отдельный от цветной иконки уведомления.

Сохраняйте исходное соотношение сторон. Для полного названия предпочтительна ширина от 160 px; при меньшем размере используйте отдельную «ф». Для письма ширина 190–220 px даёт достаточную читаемость без зависимости от шрифтов почтового клиента.
