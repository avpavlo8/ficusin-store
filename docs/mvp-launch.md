# Запуск MVP «Фикусин»

## Что входит

- каталог, цена и остаток из Saby Retail;
- корзина и гостевое оформление заказа;
- поиск города, расчёт тарифа и выбор ПВЗ СДЭК;
- онлайн-оплата через ЮKassa;
- сохранение заказа и его состава в D1;
- уведомление о новом заказе через Telegram Bot API;
- обновление статуса оплаты по webhook ЮKassa.

Авторизация, скидки, оптовые правила, статьи и сложная админка не блокируют
первый запуск.

## Защищённые настройки

Значения из `.env.example` добавляются в настройки рабочего окружения. Секреты
нельзя отправлять в чат, добавлять в Git или записывать в `.openai/hosting.json`.

## Saby

Интеграция использует Saby Retail API v2:

- каталог: `GET https://api.sbis.ru/retail/v2/nomenclature/list`;
- заголовок: `X-SBISAccessToken`;
- цена берётся из `cost`, остаток — из `balance`;
- синхронизация запускается защищённым запросом
  `POST /api/integrations/saby/catalog`.

На сервере следует запускать синхронизацию каждые 5–10 минут. Перед запуском
нужно проверить, что в выбранном прайс-листе цена указана в рублях, а артикулы
уникальны.

## СДЭК

Для расчёта используются API v2 и отдельные ключи интернет-магазина. До
публикации каждого товара необходимо заполнить массу и габариты упаковки.
Текущая первая версия использует временную оценку 2 кг и 30×30×60 см на одну
позицию. Она подходит только для технического теста и не подходит для реальных
расчётов крупных растений.

## ЮKassa

После создания заказа сервер создаёт платёж с ключом идемпотентности, равным
номеру заказа. Покупатель перенаправляется на страницу ЮKassa.

Webhook:

`POST https://<домен>/api/payments/yookassa`

Сервер не доверяет содержимому webhook: он повторно получает платёж из ЮKassa и
только затем меняет статус заказа. Значение `YOOKASSA_VAT_CODE` и состав чека
нужно согласовать с бухгалтером до приёма реальных денег.

## Telegram

Бот должен быть добавлен в рабочую группу или личный чат. Для отправки нужны
токен бота и `chat_id`. Ошибка Telegram не отменяет уже сохранённый заказ.
