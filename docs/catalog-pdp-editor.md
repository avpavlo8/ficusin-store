# Наполнение каталога и редактор PDP

Для сотрудников с правом `products.edit` карточка товара показывает служебную панель. Из неё можно открыть существующий редактор товара, управлять галереей и запустить массовый импорт актуального справочника СБИС.

Массовый импорт читает локальный `saby_nomenclature` после штатной синхронизации СБИС и использует тот же идемпотентный механизм, что импорт по артикулу. Уже существующая связь по `products.saby_id` получает статус `exists`; вторая карточка не создаётся.

Загруженные вручную фотографии сохраняются в настроенное S3-хранилище в двух размерах (карточка каталога и PDP). Секреты S3 остаются на сервере. Можно удалить снимок и назначить другой главным.

Обычное сохранение описания или характеристик не заменяет галерею. Старое поле URL фотографии сохраняет обратную совместимость и заменяет галерею только когда URL действительно изменён.
