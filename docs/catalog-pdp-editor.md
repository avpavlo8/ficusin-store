# Редактор товара из PDP

Для сотрудников с правом `products.edit` карточка товара показывает служебную панель. Из неё можно открыть существующий редактор товара и управлять галереей прямо на PDP.

Наполнение каталога из СБИС остаётся через существующий интерфейс импорта по артикулам. Этот редактор не добавляет отдельный массовый импорт и не меняет текущую логику создания карточек из СБИС.

Загруженные вручную фотографии сохраняются в настроенное S3-хранилище в двух размерах (карточка каталога и PDP). Секреты S3 остаются на сервере. Можно удалить снимок и назначить другой главным.

Обычное сохранение описания или характеристик не заменяет галерею. Старое поле URL фотографии сохраняет обратную совместимость и заменяет галерею только когда URL действительно изменён.
