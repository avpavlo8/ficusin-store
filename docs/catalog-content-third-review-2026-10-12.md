# Третий пакет контента растений — контроль качества

Снимок: публичный API после релиза #485, 319 опубликованных растений. Из 98 карточек без ухода этот пакет охватывает 64 точных PDF X/SKU. Миграция заполняет только пустые поля и требует совпадения product_code, названия и раздела plants. Дополнительно 9 точечных исправлений Latin имеют guard старого значения и источник.

Для 15 вариантов диаметр D взят из точного X/SKU и названия PDF. SQL требует совпадения кода СБИС и одного активного варианта, а также пустого диаметра. Высоту, цену, фото, статус и остаток пакет не меняет.

Паспортные советы «Свет» и «Полив» формируются отдельно. Общее введение в уход показывается над тематическими вкладками, а не во вкладке «Свет».

## Источники

Профили и точные поправки содержат ссылки на первичные страницы RHS, NC State Extension и Kew прямо в `scripts/generate_curated_plant_content_third.py`. Вид/сорт не выводится из одного лишь сходства названия, если торговое имя не даёт однозначной идентификации.

## Готовность каталога

На снимке 139/319 карточек без подборок; принадлежность к подборкам рассчитывается по PIM признакам. Без подтверждённых данных о безопасности для животных не присваиваем pet-safe. Админка показывает 310/319 без обязательных характеристик, в основном из-за пустой высоты: 334/350 SKU не имеют heightCm, 42/350 не имеют potDiameterCm. Пакет сокращает только 15 случаев с диаметром, прямо указанным в PDF. Высота требует замера конкретного экземпляра и не выводится из видового описания.
