# Оставшаяся совместимость с сохранёнными данными

Актуально после локального переноса 14 ноября 2026. Production не обновлён:
инвентаризация и чтение S3/API выполнены без изменений данных. Новые миграции
проверяются локально. [Порядок переноса и доказательства](legacy-data-transition.md).
Исторические миграции и архивные данные не удаляются.

## Снятые рабочие пути

- Старое чтение `bytea` удалено из API аватаров, чата, возвратов/уценки,
  документов закупок и отзывов. Адаптер публичного бакета отзывов удалён.
  До включения такого runtime миграция требует отсутствие неперенесённых
  файлов, архивирует исходные байты/метаданные и проверяет точность копии.
  Перед применением обязателен полный S3 verify всех источников.
- Прежние `ReleaseStock`, `RecordStockRelease`, освобождение резервов при
  редактировании и очистка старых распределений shipment offer удалены.
  Барьер миграции требует нули, сохраняет исторические значения и запрещает
  восстановление прежних резервов. Физические остатки и FIFO не обнуляются.
- Удаление вариантов/черновиков больше не читает
  `legacy_archive.catalog_saby_exports`. Полная история переносится в
  неизменяемый `catalog_external_operation_history`, который сохраняет защиту
  внешней идентичности даже при удалении рабочего товара.
- Редактор использует нормализованный V2; распределённые fallback-пути старого
  одно-вариантного формата и общего артикула из UI удалены.

Автономные команды `migrate-file-assets` и `reconcile-legacy-reservations`
остаются инструментами перехода для исходных копий данных. Они не запускаются
API или worker. Планирование — по умолчанию; перенос файлов требует `--apply`,
а применение резервов допускается только в специально названной локальной БД.
Это не дополнительные рабочие обработчики отключённых функций.

## Браузеры, ещё не открывавшие новую версию

Ключи `ficusin:product-creation-draft:v1` и
`ficusin:product-edit-draft:v1:<id>` сохранены, но значение теперь `version:2`.
Импортёр сначала сохраняет точную исходную строку в отдельный неизменяемый
backup, затем нормализует варианты, артикулы, ID, вкладки и связи. Ошибка формата
или квоты не позволяет перезаписать исходник или отправить повреждённый план.

Прежние Blob в IndexedDB преобразуются в бинарные записи вместе с бинарным
backup в одной транзакции. Новый writer сохраняет только ArrayBuffer и MIME.

**Условие удаления импортёра:** подтверждённый перенос всех пользовательских
устройств либо согласованная политика окончания поддержки старых черновиков.
Сервер не содержит их полного списка, поэтому нулевые SQL-счётчики не позволяют
удалить этот небольшой читатель без потери работы пользователя.

## Неизменяемые команды площадок

Редактируемые `catalog_editor_plans` нормализуются с точным исходным JSON в
`catalog_plan_format_history`. Новые сохранения материализуют артикулы каналов.

`catalogeditor.Marketplace.SellerArticle` и `Request.SellerArticle` пока читают
общий артикул старых замороженных запросов. Их используют построение payload,
проверки принадлежности при повторе и pending revisions. Даже терминальный
receipt может быть источником защищённых полей следующего обновления.
Явно пустой артикул не наследуется.

**Условие удаления:** сверить внешние операции и перейти на новые явно
сохранённые запросы. Нельзя менять исходный fingerprint, progress и pending
payload или сбрасывать неизвестный результат ради удаления reader.
Агрегированное представление `catalog_compatibility_inventory` показывает
оставшиеся блокеры. [Контракт миграции](catalog-compatibility-migration.md).

Рабочая сверка нашла существующую карточку WB и недозаполненный черновик СБИС.
Их запросы и ссылки сохранены, создание/обновление извне этим переносом не
выполнялось. Восстановление публикации является отдельной операцией и может
изменить фото, контент и цену на площадке.

## Поддерживаемая альтернативная формула цены

`procurement.LegacyMarketplacePrices` вызывается действующими quote/calculator/
plan путями, когда `economics.unified.enabled=false`. API настроек по-прежнему
разрешает эту конфигурацию. В production общая модель включена, но само имя
`Legacy` не превращает альтернативу в неиспользуемый код.

**Условие удаления:** выбрать единственную поддерживаемую модель, убрать
переключение в UI/API и согласованно перенести настройки. Эта очистка не
пересчитывает цены и не отключает действующую конфигурацию по догадке.
